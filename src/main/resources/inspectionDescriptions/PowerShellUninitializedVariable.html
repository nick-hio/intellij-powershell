Reports variables that may be read before assignment in the current file, including reads before a later assignment and assignments made on only some branches. Parameters, automatic variables, known outer captures and explicitly scoped/provider variables are excluded.

PowerShell can create variables dynamically or supply them from a calling scope, dot-sourced script, or module. This inspection cannot prove those variables exist. Disable the inspection for code that intentionally relies on an external scope, or make dependencies explicit with parameters.
